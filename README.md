# ETF-Simulator

## Beschreibung

Eine statische Webanwendung zur Simulation von ETF-Investments. Berechnet Vermögensentwicklung, Sparpläne, Renditen und Zinseszinseffekte direkt im Browser anhand verschiedener Parameter. Das Tool ist speziell für Deutschland ausgelegt und berücksichtigt relevante steuerliche Regelungen, wie z. B. die Abgeltungssteuer und weitere in Deutschland geltende Besonderheiten bei ETF-Investments.

## Benutzung von KI

Ki wurde innerhalb dieses Projektes für Recherche und Vereinfachung repetitive Aufgaben verwendet. Die Grundlegende Logik und Umsetzung dieser kam rein von mir.

## Warnung

Dies ist ein Tool was möglichen Wachstum darstellt, aber nicht garantiert. Verwende es nicht um finanzielle Entscheidungen zu treffen.

Das Projekt ist Work in Progress
